10 / 11 · 실제 공고 확인 세 가지는 모두 AI 없이 코드로 한 것

[약 50초] 지금까지의 진행 상황입니다. 왼쪽 엔진은 바뀐 부분 찾기, 변경 기록과 재생, 영향받는 사람 판정, 자격 예정일 계산까지 완료했습니다. AI로 바뀐 부분만 다시 읽는 부분은 코드는 준비됐고, 실제 공고로 정확도를 재는 건 11월에 합니다. 오른쪽 서비스는 공고 수집, 첨부 문서 읽기, 정정해서 다시 올린 공고 묶기까지 됐고, 화면과 전체 흐름 연결, 알림이 남았습니다. 아래 줄처럼 실제 공고로도 확인해 봤는데, 정정해서 새로 올린 공고 7건을 모두 바르게 묶었고, 정정 때 다시 읽어야 할 부분은 중앙값 8%였고, 가상 사용자 10만 명을 약 5초에 다시 판정했습니다. 이 세 가지는 모두 AI 없이 코드로 확인한 결과입니다.
