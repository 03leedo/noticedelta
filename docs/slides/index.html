코드 판정·알림

  • LLM 호출은 바뀐 문단 수만큼만 생기고 사용자 수와 무관하다
  • 자격 판정은 결정적 코드가 하고, 결과는 해당 / 비해당 / 확인 필요 세 가지에 근거 조항을 붙인다

  • 첨부 파서 격리와 권한 분리는 앞선 과제(에이전트 격리·권한 조사)에서 정리한 내용을 참고했다
