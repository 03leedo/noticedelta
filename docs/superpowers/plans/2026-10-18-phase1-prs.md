# 1단계 작업 목록 (PR 단위)

> [DESIGN.md](../../DESIGN.md) v0.5 14장 일정(12/14 동결)을 PR 단위로 나눈 목록.
> 상태는 PR을 열고 닫을 때 이 표에서 고친다.

## 작업 방식

- PR 하나는 검증 가능한 결과 하나. 대략 200~600줄, 1~2일 분량을 넘기지 않는다.
- 승인 절차 없이 **CI 통과를 확인한 뒤** 직접 merge한다. merge는 커밋을 살리는 merge commit.
- 문서·설정 같은 작은 변경은 main에 바로 push해도 된다.
- 테스트는 네트워크·API 키·Docker 없이 돈다. 실제 응답은 `data/samples/`(gitignore)에만 두고, 픽스처는 확인한 형태를 따라 가상 값으로 만든다.
