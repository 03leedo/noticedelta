# 정답 라벨 지침 (v1, 2026-10-30)

> DESIGN.md 12.1. 이 문서는 **라벨을 달기 전에 고정**한다. 바꾸면 버전을 올리고, 이미 단 라벨은 옛 버전으로 남긴다.

## 1. 무엇을 라벨하나

- **단위**: (정정, 필드). 정정은 한 사업의 이전 버전 → 이후 버전 한 쌍이다.
- **필드**: 마감일(`deadline`), 지원 금액(`amount`), 신청 자격(`eligibility_rules`), 제출 서류(`required_documents`), 문의처(`contact`). 한 정정마다 다섯 필드 모두에 라벨을 단다.
- **엔진 결과를 보기 전에** 단다. 라벨 화면은 엔진의 조각 비교를 보여 주지 않는다. API 응답 값 비교, 본문 비교, 첨부 원본만 본다.
- 화면: `uv run python scripts/label.py` → http://127.0.0.1:8001

## 2. 상태 네 가지

| 상태 | 언제 | 예 |
|---|---|---|
| 바뀜 (`changed`) | 정규화한 값이 달라졌다 | 마감 11/07 → 11/14, 업력 7년 → 5년, 서류 하나 추가 |
| 안 바뀜 (`unchanged`) | 값도 문구도 같다 | |
| 문구만 바뀜 (`wording_only`) | 문구는 달라졌지만 **정규화한 값이 같다** | "11월 7일(금)" → "2026. 11. 7.", "3천만원" → "30,000,000원", 같은 서류의 표 순서만 바뀜 |
| 필드 없음 (`absent`) | 두 버전 모두 그 정보가 없다 | 문의처를 적지 않은 공고 |

- 한쪽에만 있으면(새로 생김, 없어짐) **바뀜**이다. 이전·이후 값 중 없는 쪽은 비운다.
- 확신이 없으면 메모에 이유를 적고, 가장 가까운 상태를 고른다. 메모가 있는 라벨은 나중에 다시 본다.

## 3. 값 정규화

이전·이후 값 칸에는 아래 형식으로 적는다. 원문을 길게 옮기지 않는다.

| 필드 | 형식 | 예 |
|---|---|---|
| 마감일 | `YYYY-MM-DD` 또는 `YYYY-MM-DD HH:MM` (24시간) | `2026-11-14 18:00` |
| 지원 금액 | 기업당 최대 금액, 원 단위 정수, 쉼표 없음 | `30000000` |
| 신청 자격 | 바뀐 조건만 `속성 연산자 값`으로, 여러 개면 `;` | `업력 <= 60개월; 대표자 나이 <= 39` |
| 제출 서류 | 서류 이름을 가나다순으로 `;` | `사업계획서; 사업자등록증 사본` |
| 문의처 | 전화번호는 `000-0000-0000`, 기관명 없이 | `051-123-4567` |

- 신청 자격의 속성 이름: 업력(개월), 대표자 나이, 소재지, 업종, 사업자 형태, 매출(원), 상시 근로자 수, 예비 창업자, 여성기업, 재창업. 사전에 없는 조건은 짧은 말로 쓴다("중복 수혜 제외").
- "N년 이내"는 개월로 바꾼다(7년 이내 → `업력 <= 84개월`).
- 날짜에 요일·마침표·공백이 달라도 같은 날이면 같은 값이다.

## 4. 근거 위치와 어디서 보이나

- **근거 위치**: 정답을 찾은 곳을 짧게. `공고문.hwp 2쪽 표1 신청자격`, `본문 셋째 문단`, `API reqstBeginEndDe`. 원문 문장은 붙이지 않는다(공개할 때 위치만 남긴다).
- **어디서 보이나**: 변경을 처음 확인할 수 있는 곳 하나.
  - `API 메타`: API 응답의 구조화된 값(접수 기간 등)만 봐도 알 수 있다.
  - `본문`: API 본문(사업 개요) 글에서 보인다.
  - `첨부`: 첨부 파일을 열어야만 보인다.
- 여러 곳에서 보이면 위 순서(API 메타 → 본문 → 첨부)에서 앞에 있는 것을 고른다.

## 5. 2차 라벨과 일치도

- 1차 라벨을 단 지 **7일 이상** 지난 정정 중 무작위 **30%**를 다시 단다. 화면의 `2차 라벨`에 나오고, 1차 답은 보이지 않는다.
- 일치도는 필드별 상태로 비율과 Cohen's kappa를 낸다(화면의 `일치도`). 가능하면 두 번째 사람이 `--labeler` 이름을 바꿔 같은 30%를 단다.

## 6. 공개

원문은 공개하지 않는다. 공개 산출물은 사업·버전 ID, 첨부 내용 해시, 라벨(상태·정규화 값·위치·어디서 보이나)과 생성 스크립트뿐이다(기업마당 공공누리 3유형, K-Startup 약관).
